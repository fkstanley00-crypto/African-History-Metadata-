# African-History-Metadata-
A collection of metadata related to African history sources.
The CSV file contains metadata for African history sources collected from various digital archives such as Internet Archive, Europeana and Open Library. 
Fields Included in the Dataset: The dataset includes the following metadata for each item:
Title
Author/Creator
Date of Creation
Description
Keywords or Subject Tags
Source 
License Type 

The purpose of this project is to organize and share metadata related to African history sources. This dataset provides a curated collection of works that explore various aspects of African history, including slavery, colonialism, and Pan-Africanism. By organizing and sharing this metadata, the project aims to enhance access to key sources and improve understanding of Africa's historical context.
